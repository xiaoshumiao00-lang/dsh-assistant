# 产品文案 · 个人助手（dsh-assistant）

> 这一页是上架用的正文。口径与源码实测一致，不写「大概」的数：写错的数字会被下架。

## 它是什么

**一颗悬浮球 + 一条常驻秘书 + 一块跨端控制室。**
装在**你自己的电脑**上（DeepSeek Harness 桌面宿主的扩展），把你这台电脑变成一个能被手机随时指挥的
「个人助手工位」：

- 按 **Ctrl+Alt+A**、或**单击**右下角那颗悬浮球 → 直接进**个人秘书**那条固定会话，日常小事一句话就说完了；
- **长按 600 ms** → 打开**控制室**：项目卡片、会话列表、模板流程、新建会话、添加项目，四件都在同一屏；
- 手机（安卓壳 APK 或任意手机浏览器）**连上同一台电脑**，拿到的是同一份前端、同一个会话、同一套插件；
- 秘书会**主动把结果做成卡片**给你看（标题 + 摘要 + 要点 + 展开详情），卡片头部带**朗读按钮**，能直接听。

技术上它是一个 DSH 插件包：宿主半部 + 客户端半部 + 手机访问半部 + Computer Use 接入（vendored），
版本号 0.2.41，安卓壳 1.4.10（versionCode 37）—— 1.4.9 相对 1.4.8 只把壳里预置的作者本机入口换成占位文案；
1.4.10 新增「检查更新 + 一键下载安装」，默认关闭、默认不联网、更新源要你自己填 `owner/repo`、24 小时只查一次、不后台自动联网。功能其余未变。许可 **GPL-2.0**（第三方条目见 `NOTICE`）。

## 卖点（逐条都是本机实测行为，不是承诺）

1. **一键唤起，不用找窗口**：全局热键 Ctrl+Alt+A、单击悬浮球都进个人秘书（页面不在前台也能唤起）；
   长按 600 ms 进控制室；网页地址加 `?assistant=chat` 直达秘书。手势与目标的对照表在源码里，有单测断言。
2. **个人秘书主动服务卡片**：需要电脑动手的活，秘书把它派给 Computer Use 会话，跑完在秘书会话里落一张
   结构化卡片（标题 / 摘要 / 要点 / 详情 / 时间），带未读红点与引用锚点，历史可翻页滚动连续。
3. **控制室跨端同步**：项目卡片与视图的真值在宿主的 profile 状态文件里，手机与电脑两端同源读写；
   带 revision 乐观并发控制，两端同时改不会互相盖。
4. **手机访问入口**：局域网入口（默认 3081，开着就必带密码）或公网入口（Cloudflare 命名隧道 / SSH 反向隧道）；
   8 位访问密码、握手 cookie、30 天免输。安卓壳带**后台保活**（前台服务 dataSync、常驻通知、
   `START_STICKY`、9 分钟 Doze 节拍）与**切回秒恢复**。
5. **语音朗读与语音输入**：卡片正文可用 `edge-tts` 合成 MP3 听（默认晓晓音色、语速 +45%）；
   语音转写带**你自己的人名/校名/店名词表**纠偏。后台任务完成会在安卓侧播报。
6. **目录边界（allowlist）安全口径**：文件通道、静态托管、终端最小环境变量都在一份允许根之内；
   越界 403、盘符根单独拒、`..` 遍历拒；手机上传有 25 MB 上限与保留名拒绝。
   拆边界的两个危险字段**只有本机回环能写**，关掉边界还要带**运行时生成的一次性随机口令**
   （不在源码/仓库/构建产物里，用完即刻换新）。
7. **日志与配额卫生**：turn-guard 判定日志只落标识（不落回复正文、不落本机绝对路径），
   超过 200 KB 自动轮转到 `.1`，行内截到 240 字符；诊断包导出前统一脱敏。
8. **不绑架你的更新**：`updateCheckEnabled` 默认关闭、`updateSource` 默认为空 —— 默认不联网检查，
   不会被「升级」成别人机器的构建。

## 上架正文建议（短版）

**一句话**：给自己电脑装一颗悬浮球 —— 一句话派活、卡片汇报、手机随时接手。

**三行**：
- Ctrl+Alt+A 或单击悬浮球进个人秘书，长按 600 ms 开控制室；
- 手机连上同一台电脑：同一份界面、同一个会话、同一套插件，后台保活 + 朗读；
- 文件通道在目录 allowlist 以内，危险字段只能本机回环写，拆边界要一次性口令。

## 文案红线（这一节给上架的人自查）

- 不写真实 IP、真实域名、真实账号、商户号、AppID、支付密钥、口令值、token 值；
- 不写作者本机私人路径（`D:\...`、`C:\Users\...` 这类一律换成 `<你的目录>` 占位）；
- 不写「npm 装 dsh-assistant」—— 公开 npm 上那个同名包是别人的项目，上架与安装只走第三方源
  `github:xiaoshumiao00-lang/dsh-assistant`；
- 不承诺「不需要电脑」：插件必须跑在你自己那台装着 DSH 宿主的电脑上；
- 不把 GPL-2.0 说成「闭源授权」。
