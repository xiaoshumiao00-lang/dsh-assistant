# 安装与部署手册 · 个人助手（dsh-assistant）

> 这份手册是给**拿到上架包的人**写的：在你自己的电脑上装好插件，在你自己的电脑上开手机访问入口，
> 在你自己的手机上装 APK 连上你自己的电脑。全程不需要作者的机器、VPS 或任何账号。
> 插件版本：0.2.43（见 `package.json`）；安卓壳版本：1.4.10（versionCode 37）。

---

## 1. 前提（必须先满足）

| 项 | 要求 | 说明 |
| --- | --- | --- |
| 操作系统 | **Windows 11**（Windows 10 也可，功能一致） | 插件页面与悬浮球跑在这台电脑上，电脑要开着并装着 DSH 桌面宿主 |
| 宿主 | DeepSeek Harness 桌面版（DSH Desktop）≥ 0.1.5 | 本插件是 DSH 的扩展，**不能单独运行** |
| Node.js | **≥ 22** | 命令行安装 / 源码构建都要 Node 22；插件的测试脚本也直接跑 `.ts`（靠 Node 22 的类型剥离） |
| 网络 | 能访问 GitHub | 安装要拉一次仓库 |
| 手机 | Android 7.0+（API 24，目标 API 34） | 只有想用手机访问时才需要装 APK；不想装就用手机浏览器 |

macOS / Linux 可用但降级：原生桌面悬浮球需要 Electron 运行时，没有就用页面内球；`.command`/`.sh` 安装脚本尚未提供。

许可：**GPL-2.0**（整包）。转发必须连同源码与 `LICENSE` / `NOTICE` 一起；第三方条目见 `NOTICE`。

## 2. 装插件（第三方源：GitHub，不用 npm）

### 2.1 桌面版（推荐，点两下）

1. 打开 DSH → 左侧 **「插件」** 页
2. 点 **「添加插件 / Add plugin」**
3. 粘贴下面这一整行，回车：

   ```
   github:xiaoshumiao00-lang/dsh-assistant
   ```

4. 等它拉包、装依赖（第一次几十秒到几分钟）→ **完全退出并重启 DSH Desktop**（宿主改动必须重启）

### 2.2 命令行（`dsh web` / 服务器 profile）

```bash
dsh plugin --profile web add github:xiaoshumiao00-lang/dsh-assistant
```

> 桌面版不要用命令行：`--profile desktop` 由 Electron 独占，命令行会直接报
> `profile "desktop" is managed exclusively by the Electron application`。桌面版走 2.1。

### 2.3 ⚠️ 千万别装错（这一条很重要）

**不要**在「添加插件」里只填 `dsh-assistant`，也不要 `npm install dsh-assistant`。
公开 npm 上的 `dsh-assistant@0.2.3` 是**别人的同名包**（maintainer `vianvio`、
repo `github.com/vianvio/dsh-assistant`、MIT），跟本插件毫无关系。
上架与安装一律走第三方源：

```
github:xiaoshumiao00-lang/dsh-assistant
```

本插件**没有 npm 发布**，任何说「npm 装 dsh-assistant」的步骤都是错的。

### 2.4 装好了怎么确认

重启后应看到：

- 左侧导航多出 **「个人助手」**；
- 屏幕右下角出现**悬浮球**（界面内也有一颗）；
- **设置 → 个人助手**（里面有「手机访问」「本机配置」「Computer Use」「托管」等 tab）。

## 3. 悬浮球快捷键（实测口径）

| 动作 | 结果 |
| --- | --- |
| **Ctrl+Alt+A**（全局热键） | 直接进**个人秘书**那条固定会话（页面不在前台也能唤起） |
| **单击**悬浮球 | 直接进**个人秘书** |
| **长按 600 ms**（按住不放、期间不拖动） | 打开**控制室**（项目卡片 / 会话 / 模板流程 / 新建会话） |
| 按住拖动 | 挪球位置，移动中不触发点击 |
| 网页地址加 `?assistant=chat` | 直达个人秘书（`?assistant=console` 直达控制室） |

两颗球（窗口内 / 窗口外）手势相同。想改球外观或关掉外部球：设置 → 个人助手 → 悬浮球。
长按判定阈值就是 600 ms；手势与目标的对照表在源码 `src/desktop-ball.ts` 的 `BALL_GESTURE_INTENT`，
有单测断言，改反会红。

## 4. 手机访问入口（在你自己电脑上开）

设置 → **个人助手** → **📱 手机访问**。默认是「局域网关闭 + 局域网要密码」；要扫码先在设置里开一下。

| 场景 | 怎么做 | 你会拿到的地址 |
| --- | --- | --- |
| 同一个 WiFi（最简单） | 开 **局域网访问** 开关 | `http://<你的电脑IP>:3081` |
| 要在外面用（公网） | 二选一：Cloudflare 命名隧道（需要自己的域名 + Token）／SSH 反向隧道（需要自己的 VPS） | 你自己的固定地址 |

- 端口默认 **3081**（想换就在设置里改 `proxyPort`；被占用时插件启动会失败，改端口重启即可）。
- 同一时间只建议开一种入口。开公网入口前想清楚：这台电脑上能执行任意命令，
  密码与扫码链接等于控制权，别外发、别截图、别贴进聊天记录。
- **访问密码（8 位）只在你这台电脑的显示界面上看**：本机浏览器打开 DSH 的设置页
  （或在本机上问 `GET /api/assistant/...` 的那类回环路由）。这份手册与上架包里**不写任何真实 IP、
  不写任何真实密码**；填地址时一律填你自己电脑的地址。
- 语音输入要 https（或 `localhost`）入口；纯 `http://IP` 浏览器不给麦克风权限。

在手机上第一次连：输一次密码，之后 30 天免输，地址也记住。换地址：**长按桌面图标 → 设置地址**。

## 5. 装 APK（安卓外壳）

包内交付的 APK：`安装包/个人助手-通用版-1.4.10.apk`（99,187 字节，sha256 `3473E642D356D417A7B4B31229BD0E7E66381A3D7F9D0504B0F88F50FFA63F24`；
与 `android\dist\` 那份逐字节一致，本轮现场 `Get-FileHash` 重测）。旧版 1.4.9 不再上架，仍留在仓库忽略的 `android\dist\` 档案目录。

1. 把 APK 传到手机，允许一次「未知来源」并安装。
2. 打开「个人助手」→ 第一次进设置页 → 填第 4 步拿到的地址 → 点「连接」。
3. 输一次访问密码（见第 4 步）。不想装 APK 也行：手机浏览器直接打开那个地址，界面一模一样。

**⚠️ 升级必须用同一把签名密钥**：Android 覆盖安装要求新旧 APK 是同一个签名。
换签名密钥出包 = 用户必须先卸载旧版再装新版（会丢手机本地的浏览器状态）。
签名 keystore 不在仓库里，也不在这个上架包里；出新版包的人要在自己电脑上保留原来那把密钥。

包名 `<PKGID-FORM>（形态 len=29 sha256 前 10 位 0193D337E3）`，最低 API 24 / 目标 API 34，当前 versionCode 37 / versionName 1.4.10。
**这份壳从 1.4.9 起就没有预置作者本人的入口地址**（原来是硬编码公网入口 + 局域网示例地址，
1.4.9 换成空值与通用占位，见《交付清单》第 3 节）：首次打开仍进设置页，你必须自己填 `http://<你的电脑IP>:3081`
这类地址；空着点保存会提示「地址不能空着」，不填就不能连。旧版 1.4.8 不再上架，只在仓库档案目录保留。

### 5.1 在手机上检查更新并一键装新版（1.4.10 起）

**默认是关闭的，关闭期间这个应用完全不联网。** 要检查更新得你自己开、自己填：

**第 0 步（必须先做，否则「检查更新」用不了）：在自己的 GitHub 仓库里建 1 个 Release，并把新版 APK 作为它的资产挂上。**
- 壳只读这一条地址：`https://api.github.com/repos/<你的账号名>/<你的仓库名>/releases/latest`（代码里的 `UpdateCheck.validatedApiUrl`），
  拿到 `tag_name` 比对版本、再从那个 release 的 `assets` 里挑 `.apk` 的 `browser_download_url` 去下载。
- **仓库只有 tag、没有 Release 时这条地址回 404**，壳就照实提示「这个仓库没有 release」，**不会自动去读 tag**（代码里没有读 tag 的分支）。
- 现场实测口径（本轮跑过、不是推测）：只带 tag 的仓库 → `/releases/latest` = **404 `Not Found`**、`/tags` = 200 列出那两枚 tag、`/releases` = 200 但是空数组；
  对照一个已经带 Release 的公开仓库，同一个 `/releases/latest` = 200 且带 `tag_name` 与 `assets`。三者同时成立 = 「必须建 Release」这条口径的证据。
- 建法（网页版，三步）：仓库页 → **Releases** → 「Create a new release」→ 填 tag（例如 `v0.2.43`）与选中的提交 → 在 **Assets** 里把
  `安装包\个人助手-通用版-1.4.10.apk` 这种 `.apk` 文件拖进去上传 → 「Publish release」。命令行版：`gh release create <tag> --title <标题> <那枚 .apk 的路径>`。
- 资产名要以 `.apk` 结尾（或 content type 是 `application/vnd.android.package-archive`），且地址必须落在同一个 `owner/repo` 下的 https 链接——壳才允许它进下载队列。
- 一次 Release 只挂你要装的那一版；老版本留着不动也行。**只有 tag 不行、只挂源码 zip 也不行。**

1. 打开「个人助手」→ 按返回键（回到首页那一步会弹出菜单）→ 选「设置地址」进设置页；
   在「检查更新（默认关闭）」区块里点「检查更新：已开启」把开关打开。
2. 更新源照 `owner/repo` 填**你自己的** GitHub 账号名/仓库名（例如 `你的名字/你的仓库名`），点「保存更新源」。
   形态不对（带域名、带端口、多一段斜杠、空格…）会直接拒、并照实说明「没有发出任何请求」；**留空就是不联网**。
3. 检查：后菜单选「检查更新」或设置页点「检查更新（手动查一次）」。**只有你按下去才发一个请求**，
   只连 `api.github.com`（协议必须是 https，host 必须恰好是这个，不许重定向、不许带端口），一次点按只发 1 个请求，
   查完就停 —— **不遥测、不后台自动查、不定时唤醒、不装任何后台服务**。
4. **24 小时内只查一次**：同一小时内再点会回「这次没再联网」并给还差多久；上一次查到的结果留在本地缓存里。
5. 发现新版本 → 弹窗「检查更新」→「下载并安装」（系统下载队列里有进度通知）→ 下载完自动弹**系统安装界面**，
   点「安装」确认。应用没法自己静默装。
6. **必须先允许这个应用装应用**：Android 8 起，系统要求给「安装未知应用」授权；没授权时壳会先弹
   「要装新版，先允许这个应用装应用」，点「去设置」跳到系统那条授权页（你自己开关），
   也可以点「只下载」——新版会落到系统「下载」里，你在下载通知或文件管理器里点它一样能装。**壳不会自动授权**。
7. 「这版不装」：这个版本的忽略记号写进应用自己的持久化设置，同一个版本号以后不再提示；要恢复就在设置页点「取消「这版不装」，恢复提示」。
8. 检查失败会照实说（403 限流/要登录、404 这个仓库没有 release、读不出 JSON、没有可用的 APK 资产…），
   **不会把失败说成「已经是最新版」**。设置页的状态行也会显示当前更新源、节流还剩多久、「这版不装」是否记着。

清单权限本轮**净新增 0 项**：`REQUEST_INSTALL_PACKAGES` 从 1.4.7 起就在清单里，本轮没加新权限、
没新增 FileProvider（安装那条走的是 DownloadManager 的 `content://` Uri + 临时读授权，见《交付清单》第 3 节）。

## 6. 本机个人化配置（不入库，装完就该填）

界面改（推荐）：设置 → 个人助手 → **🧩 本机配置**（四个分组：目录与路径 / 语音词表 / 目录边界 / 更新检查）。
手改 JSON：`~/.dsh/assistant/config.json`（兼容旧位置 `<DSH_HOME>/dsh-assistant-config.json`，
或环境变量 `DSH_ASSISTANT_CONFIG` 显式覆盖）。字段名与空白模板见 `配置模板/`。

| 字段 | 作用 | 不填的兜底 |
| --- | --- | --- |
| `newProjectParent` | 新建项目的默认父目录 | 平台 Desktop → 助手目录下 `projects/` |
| `skillRoot` | 技能文件路径的前缀 | `<DSH_HOME>/skills` |
| `asrTerms` | 语音转写的个人词表（人名 / 校名 / 店名） | 空 = 只纠通用词 |
| `allowedRoots` | 目录边界（allowlist）追加根 | 默认根已含助手目录 / DSH 数据根 / 桌面 / 项目父目录 / 技能根 / 临时目录 / 用户主目录 |
| `allowAllLocalPaths` | 逃生开关：关掉目录边界检查（**危险**） | `false` |
| `persona` | 写进助手 `AGENTS.md` 的本机人设段 | 不注入 |
| `termEnvAllow` | 终端最小环境变量追加项 | 只有内置白名单 |
| `updateSource` | 更新源 `owner/repo` | 空 = 不联网检查 |
| `updateCheckEnabled` | 是否允许检查更新 | `false` |

改完 `allowedRoots` / `allowAllLocalPaths` **不用重启**：目录 allowlist 每次请求重读本机配置。

### 6.1 危险字段只允许本机回环写

`allowAllLocalPaths`（拆边界）与 `allowedRoots`（拉宽边界）**手机 / 公网来源一律拒写**，
即使那条请求已经带着 PIN 登录过，也会回 403 `loopback-only`。要改请在电脑上改。

### 6.2 逃生口令（一次性随机）

把边界关掉需要带**本机一次性口令**：运行时生成（`crypto.randomBytes(18)` → 24 位 base64url），
存在 `~/.dsh/assistant/escape-hatch.json`（0o600），源码 / 仓库 / 构建产物里都不出现它。
取用：设置页「本机配置 → 目录边界」按「🔑 取一次性口令」，走 `GET /api/assistant/escape-hatch`
（只在本机回环答话；非回环 403，且不回吐口令本体）。用成功一次就换新口令，旧那串即刻作废。
**这份手册里不写任何口令值。**

## 7. 更新与卸载

### 7.1 更新（插件侧）

- 桌面版：再来一次 2.1（重新粘贴同一行 `github:xiaoshumiao00-lang/dsh-assistant`）→ 重启 DSH。
- 命令行：`dsh plugin --profile web update dsh-assistant`。
- 纯客户端改动刷新页面即可；**宿主改动（路由 / 热键 / 服务）必须重启 DSH Desktop**。
- 源码装的人：`git pull` → `npm install` → `npm run build` → 重启宿主。
  ⚠️ **历史被强推过（含清洗 commit 后 `main` 被 `--force-with-lease` 重写过）的仓库，本地 `git pull` 会失败或合出不该有的一串**：
  这时要 `git fetch origin` 之后 `git reset --hard origin/main`（先确认本地没有你要留的东西；
  有本地改动就先 `git stash` 或另存一份）。已经装过插件的桌面侧不用管这条，只有源码装的用户要照做。
- `updateCheckEnabled` 默认关闭：默认不会去连别人的仓库，也不会被「升级」成别人的构建。
  要检查更新就自己填 `owner/repo`。

### 7.2 更新（APK 侧）

同一把签名密钥出包 → 直接覆盖安装；换了密钥 → 先卸载旧版再装新版（见第 5 节那条 ⚠️）。

1.4.10 起手机上可以直接走完「检查更新 → 下载 → 系统安装界面」这一条：
见第 5.1 节。**默认关闭、更新源要你自己填、24 小时只查一次、不联网就不会有任何外发请求**；
检查与下载都不影响已配的助手地址与会话数据（覆盖安装不动应用私有数据）。
没允许「安装未知应用」时壳只给你跳系统授权页的入口，不会自动授权，也不会静默安装。

### 7.3 卸载

1. 插件页里**停用 / 移除**该插件，然后**重启 DSH Desktop** 才算生效；
2. 手机侧：设置 → 个人助手 → 手机访问把入口关掉（局域网开关关掉），手机浏览器里清掉那个站点的数据；
3. 想连本机数据一起清（源码安装的人）：`node scripts\uninstall-assistant.mjs --dry-run` 先看计划，
   再 `node scripts\uninstall-assistant.mjs`（`--purge` 连数据一起清，删前会先挪进
   `~/.dsh/uninstall-backup-<时间戳>/`，可翻回来）。脚本不删会话目录 `~/.dsh/sessions`
   与宿主记忆真值 `~/.mnemon`；浏览器侧的数据（IndexedDB `dsh-worktable`、
   localStorage 前缀 `dsh.assistant.*` / `dsh.worktable.*` / `dsh-assistant.*` / `dsh-tuoguan.*` / `dsh-pocket.*`）
   脚本碰不到，会打印名单与可粘贴的 DevTools 片段。**`dsh.sessions.current` 是宿主的，不清。**

回退插件安装：把 `<用户目录>\.dsh\profiles\<profile>\package.json.bak-assistant-<时间戳>` 复制回 `package.json`，重启即可。

## 8. 装完自检

跑 `脚本/自检.ps1`（在本机 PowerShell 里跑）。它打印 4 项：

1. 插件版本（读 `package.json`）；
2. 悬浮球快捷键；
3. 个人秘书会话是否就绪（只报「已就绪 / 未就绪」与会话名「个人秘书」，**不打印会话 id**）；
4. 手机访问入口状态（只报监听端口与是否可访问，**不打印 PIN / token**）。

报错对照表见同目录《报错对照表.md》。
