# 配置模板说明

三份模板都是**空白模板**：字段名照 `README.md` 与源码抄，值全部是占位符（尖括号里该换掉）。
模板里没有任何真实 token、真实 IP、真实账号、商户号、口令值。

| 模板文件 | 对应真值文件 | 落在哪里 | 源码里谁读它 |
| --- | --- | --- | --- |
| `本机配置.config.模板.json` | `config.json` | `~/.dsh/assistant/config.json`（首选；兼容旧位置 `<DSH_HOME>/dsh-assistant-config.json`；也可用环境变量 `DSH_ASSISTANT_CONFIG` 指到别处） | `src/assistant-config.ts` |
| `手机访问.settings.模板.json` | `settings.json` | `<DSH_HOME>/dsh-pocket/settings.json`（文件权限 0o600） | `src/pocket-host/settings.mjs` |
| `环境变量.模板.txt` | — 环境变量 | 宿主进程环境 | `src/assistant-tts.ts`、`src/pocket-host/*.mjs`、`src/assistant-home.ts` |

## 怎么改（两种都行，效果一样）

1. **界面改（推荐）**：设置 → 个人助手 → **🧩 本机配置**（四分组：目录与路径 / 语音词表 / 目录边界 / 更新检查）。
   保存走 `POST /api/assistant/config`：白名单字段 + 类型校验 + 原子写（tmp→rename），保存后立即生效。
   可写字段：`newProjectParent`、`skillRoot`、`asrTerms`、`allowedRoots`、`allowAllLocalPaths`、`persona`、
   `termEnvAllow`、`updateSource`、`updateCheckEnabled`（其余字段名一律 400 `unknown-field`）。
2. **手改 JSON**：照模板改名落盘，然后刷新页面一次（宿主按 mtime 重读，不用重启）。

## 哪些字段只能在本机改

`allowAllLocalPaths`（把整条目录边界关掉）和 `allowedRoots`（把边界拉宽）等于「把这台电脑的钥匙换个说法交出去」。
手机 / 公网来源（经 pocket 代理进来的）一律拒写，即使它已经带 PIN 登录过：403 `loopback-only`。
`allowAllLocalPaths: true` 还要带**本机一次性口令**（400 `confirm-required`）；口令只在这台电脑的设置页显示，
不在源码 / 仓库 / 构建产物 / 这份模板里。

## 模板里刻意留空的东西

- 没有任何真实 IP / 域名：公网入口一律写作 `<你自己的VPS地址>`；局域网写作 `<你自己的电脑局域网IP>`。
- 没有任何真实密钥：`tunnelToken` / `DSH_ANDROID_KEYSTORE_PASS` 只能你自己生成。
- 没有商户号 / AppID / 支付密钥：这些与本插件无关，模板里也不出现。
- `proxyPort` 默认 3081（插件模式）；`dsh web` 保持 3080。改端口只需在这台电脑上改。

## 与 APK 有关的口径

安卓壳 **1.4.9 起**已把这条修掉（1.4.10 同样不带预置入口）：`MainActivity` 不再预置任何人的入口地址（第 88 行常量改空串、第 542 行注释改文字说明、
第 880 / 935 行的示例地址改成 `http://<你自己的电脑IP>:3081` 这种通用占位）。
拿到上架包的人**不需要改代码**：装完在 APK 的设置页填你自己的地址即可；
长按桌面图标 → 设置地址 也能改。旧版 1.4.8（仍带作者入口地址）不再上架，只在仓库档案目录保留。
