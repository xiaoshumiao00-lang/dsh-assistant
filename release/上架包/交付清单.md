## 4. 包里**不含**什么（逐条，都是硬口径）

- **不含作者私人记忆**：没有 `USER.md` / `MEMORY.md` 运行时记忆、没有 `~/.dsh/assistant/AGENTS.md` 的人设内容、
  没有 `~/.mnemon` 记忆真值、没有会话日志。
- **不含本机日志与 journal/notes**：没有 `~/.dsh/assistant/journal/`、`notes/`、`outputs/`、
  `dsh-assistant-focus.log`、`turn-guard.log` 等任何日志与落盘记录。
- **不含签名 keystore 与口令**：没有 `assistant.keystore`、没有 `keystore.pass`、没有任何口令值
  （签名密钥在仓库**外**的本机专用目录里，不在这个包里，本轮也没动它）。
- **不含任何私有 API key / token / PIN / 一次性口令**：配置模板里这些字段全是占位符；
  脚本与自检输出都不打印这些值。
- **不含商户号 / AppID / 支付密钥**：与插件无关的第三方业务标识一律不出现（本仓库的支付线不在这个包里）。
- **不含真实 IP / 真实账号**：手册、模板、文案、素材、脚本里出现的都是 `<你的电脑IP>`、`<你自己的VPS地址>` 这类占位符。
- **不含源码 tarball**（见第 2 节）、**不含 npm 包**（没有 npm 发布）、**不含 vendor 的修改**
  （`vendor/computer-use/**` 一字未改，只在 `NOTICE` 里补它的 MIT 版权条目）。
- **不含被排除的两张素材**：`shot-I-controlroom-cards.png`、`shot-L-interface-entries.png`
  （把作者本机真实项目卡片名渲染出来了，理由见 `素材\素材说明.md`）。

## 5. 仓库侧仍需轮换的账（上架前必做，不属于本包）

- 仓库内部档案 **`reports/`** 与 **`backup-20261120-*`** 第 1 轮**仍留有旧口令与旧 IP**；第 2 轮历史清洗已把这些档案里的个人标识（账户目录、账户名、姓名、机构缩写、私有网段、退役仓库名）按类别名掩码，**旧口令值本身仍按「已泄露」处理、不复现，也不写进本包**：
  第三方源一旦公开，历史提交与 LFS 存储仍可能被看到 —— **必须按「轮换」处理**：旧口令全部作废换新；旧 IP 从档案里清出去，
  轮换记录单独写在仓库外或私有档案里，不进这个包、不进公开仓库。
- 同理 `android\out\` 的旧解包残留已在上一轮清理（哈希 `d51f8f2`，作废值不复现），**git 历史**里的旧值由第 2 轮清洗覆盖；
  清洗后仍留在远端、只能按完整 SHA 取到的悬挂对象（旧尾巴与被 amend 取代的提交）需要 GitHub 支持删除请求才能彻底清掉，本轮按你的选择先不发起，登记为待决（见整改报告 §11.6）。
- 上架动作本身：**本轮收口已 push**（不再是第 1 版的「只 commit、不 push」口径）：`main` 按 `--force-with-lease` 强推（上限 3 次尝试）、
  附注 tag `v0.2.41` 与轻量 tag `android-shell-1.4.9` 重指到本轮最终落点并强推、旧附注 tag `v0.2.40` 从远端删除（删前先核对本轮任何引用都不依赖它）；
  清洗期间 `origin` 先移除、再按同一 URL 加回，未 fetch；远端只动 `main` 与 tag，不动其它分支与 GitHub 设置。
  自证：`git ls-remote --heads --tags origin` 全文、`git rev-list --count origin/main..HEAD` 应为 0、`git branch -r --contains` 抽查、`git status --porcelain` 与 `-uno` 干净。
  命令与输出的现场原文见整改报告 §11.6。
