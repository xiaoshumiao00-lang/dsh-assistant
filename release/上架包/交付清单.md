## 4. 包里**不含**什么（逐条，都是硬口径）

- **不含作者私人记忆**：没有 `USER.md` / `MEMORY.md` 运行时记忆、没有 `~/.dsh/assistant/AGENTS.md` 的人设内容、
  没有 `~/.mnemon` 记忆真值、没有会话日志。
- **不含本机日志与 journal/notes**：没有 `~/.dsh/assistant/journal/`、`notes/`、`outputs/`、
  `dsh-assistant-focus.log`、`turn-guard.log` 等任何日志与落盘记录。
- **不含签名 keystore 与口令**：没有 `assistant.keystore`、没有 `keystore.pass`、没有任何口令值
  （签名密钥在仓库外 `D:\dsh-assistant-signing\`，本轮也没动它）。
- **不含任何私有 API key / token / PIN / 一次性口令**：配置模板里这些字段全是占位符；
  脚本与自检输出都不打印这些值。
- **不含商户号 / AppID / 支付密钥**：与插件无关的第三方业务标识一律不出现（本仓库的支付线不在这个包里）。
- **不含真实 IP / 真实账号**：手册、模板、文案、素材、脚本里出现的都是 `<你的电脑IP>`、`<你自己的VPS地址>` 这类占位符。
- **不含源码 tarball**（见第 2 节）、**不含 npm 包**（没有 npm 发布）、**不含 vendor 的修改**
  （`vendor/computer-use/**` 一字未改，只在 `NOTICE` 里补它的 MIT 版权条目）。
- **不含被排除的两张素材**：`shot-I-controlroom-cards.png`、`shot-L-interface-entries.png`
  （把作者本机真实项目卡片名渲染出来了，理由见 `素材\素材说明.md`）。

## 5. 仓库侧仍需轮换的账（上架前必做，不属于本包）

- 仓库内部档案 **`reports/`** 与 **`backup-20261120-*`** 里**仍留有旧口令与旧 IP**（本轮没有删、也没有改它们，
  按纪律不动这些目录）。第三方源一旦公开，这些历史内容会被看到 ——
  **必须按「轮换」处理**：旧口令视作已泄露、全部作废换新；旧 IP 从这些档案里清出去，
  轮换记录单独写在仓库外或私有档案里，不进这个包、不进公开仓库。
- 同理 `android\out\` 的旧解包残留已在上一轮清理（`d51f8f2`），但 **git 历史**里的旧值不在这次清理范围内。
- 上架动作本身：只 commit、不 push（本轮纪律）；push 与 GitHub 侧的发布由人手动完成，
  并且**推之前**先做完第 5 节的轮换与第 3 节的 1.4.9 占位版。
