# 个人助手 · Android 外壳（APK）

一个 APK 两个屏：**助手屏**（电脑上 DSH 那套页面，同一份 HTML/CSS/JS、同一个会话）+ **鹈鹕屏**（`/tihu` 模拟设备页，底部一键语音输入）。
纯 Java，无 Gradle：`aapt2 → javac → d8 → jar → zipalign → apksigner`。

| 项 | 值 |
| --- | --- |
| 版本 | **1.1.2**（versionCode `7`，可覆盖升级 1.0.0～1.1.1） |
| 包名 | `com.chenpan.assistant.generic`（通用版） |
| 交付件 | `android/dist/个人助手-通用版-1.1.2.apk`（构建产物同时在 `android/out/`） |
| 签名 | `android/assistant.keystore`，alias `assistant`，口令 `dsh-assistant-2026`（**升级必须用同一把**） |
| 最低 / 目标 | Android 7.0（API 24）/ API 34 |

## 装到手机

1. 把 `个人助手-通用版-1.1.2.apk` 传到手机（微信文件传输助手 / 数据线 / U 盘都行）。
2. 点开安装，系统提示「未知来源」时允许一次（自己签名的应用，正常）。包名与旧版不同，**可以和旧版并存**。
3. 首次打开进「地址设置页」——两项都是空的。

## 首次要填的两个地址

| 输入框 | 填什么 | 常用值 |
| --- | --- | --- |
| 助手地址（DSH） | 电脑上 DSH → 设置 → 个人助手 → 手机访问 给的入口 | `http://49.234.20.84:7080` |
| 鹈鹕地址（模拟设备页） | 带 token 的 `/tihu` 链接 | `http://49.234.20.84:7080/tihu?token=96528673` |

- 两个地址**至少填一个**就能用；两个都空时点保存会明确提示，不会进一片白屏。
- 懒得复制就点 **「一键填入常用地址」**：只填还空着的那一格，不会覆盖你已经填好的。
- 只填鹈鹕地址 → 保存后直接进鹈鹕屏；两个都填 → 进上次停留的那个屏（首次进助手屏）。
- 改地址：**长按返回键约 1 秒**（或长按桌面图标的「设置地址」快捷方式）。宽屏/平板上设置页限宽 560dp。

## 切屏

- 屏幕右侧偏上有一枚半透明小圆钮（44dp）：助手屏上显示「鹈」，鹈鹕屏上显示「助」，点一下即切换（<1 次点击）。
- 两个屏的 WebView 都留在内存里：切回来**不重载**（鹈鹕屏是首次进入时才创建）。
- 切屏会 toast 提示当前屏；切走时如果正在录音，会先取消录音并提示。
- 返回键：鹈鹕屏上先页面内后退，退到底再弹菜单（回到助手屏 / 设置地址 / 重新加载 / 退出）。

## 鹈鹕屏：只剩一块铺满的显示屏（1.1.2）

- **删掉手机外壳**：注入时给 `#device` / `.bezel` 加页面自带的 `.shell-off` 类（复用 page.ts 里那套规则：去掉渐变外框、`.mics`、`.grille`、`.dock`、圆角阴影，`#screen` 只留一圈细边），没有另写一套外壳样式。
- **显示屏铺满可用区域**：宽度按屏宽等比放大（左右各留 4px），高度一直延到音量条上沿，把原来下方那块空白吃掉。
  - 缩放系数 `s = (屏宽 − 8) / 324`（324 = 320 逻辑宽 + 2 边框 + 2 安全量）；
  - 可用高 `avail = 视口高 − 8（顶部） − 240（底部语音条预留） − 6（间隙） − 14（顶部留白）`；
  - 写进 `#screen` 的逻辑高度 `h = avail / s`，夹在 **240 ≤ h ≤ 480**（480 = 320×1.5，超长屏不拉伸）。
  - 例：390×780 的屏 → s=1.179、h≈434，渲染出来宽 390、高 ≈512，正好贴到语音条上方；若整页仍出现纵向滚动，脚本会再按 `scrollHeight` 自动收一次（最多 2 次）。
- 内部沿用页面原 flex 布局：棋盘 `.board-list` 的 4 行改成 `flex:1 1 0`（行高随高度变大、上限 132px、文字垂直居中），页码页脚仍钉在底部；非棋盘态内容按原顺序自然排布，不裁切、不横向滚动。
- 硬件规格说明行（`ESP32-S3-BOX-3B · 2.4″ · 320×240 · 触摸屏`，即 `.device-title`/`.device-caption`）和页面顶部的 header 标题行在小屏**一律不显示**，省下的高度全给显示屏。
- 断线提示不丢：header 里的连接状态改由**音量条最左端一颗 8dp 小圆点**表示（青绿=已连接、红=断开、灰=连接中），每 3 秒读一次页面 `#conn`。
- 其余所有区块（文字兜底、撤回重说、事件日志、按住说话 / 选 WAV、音色与朗读设置、缩放/免按住那一排…）仍全部收进「鹈鹕设置」浮层（见下）。
- 这些只在手机窄屏（≤700px）生效：电脑 Chrome 打开 `/tihu` 或平板宽屏时，`.shell-off`、缩放、高度这些一个都不加，还是原来的 320×240 + 外壳。

## 鹈鹕设置（1.1.2：齿轮挪到音量条右端）

- 齿轮按钮不再浮在显示屏右上角，改成**音量条最右端、与滑块同一行的一枚 28dp 小按钮**（深色、细线、不高亮），点开仍是同一个「鹈鹕设置」面板；切屏圆钮保持原样。
- **默认浅色主题**：页面、显示屏、音量条、设置面板、提示胶囊、切屏圆钮一律白底深字（`#f7f8fa` / `#111827`，强调色用深一档的青绿 `#0f766e`），状态栏与导航栏图标同时转深色，不会白底白字。
- 想回原来的深色：打开「鹈鹕设置」→ 标题右侧的「深色」按钮；再点回「浅色」。选择存在本机（SharedPreferences），切屏、重启都记住，深色就是页面原来的配色，一点没改。
- 主题规则全部包在 `@media (max-width:700px)` + `html.tihu-light` 里：电脑 Chrome 打开 `/tihu` 或平板宽屏时既没有这个类、也没有这些规则，页面与改动前完全一致。
- 面板是深色圆角半屏浮层，内部可滚动；点「关闭」或点浮层空白处都能收起。
- 面板里是**原样搬过来的真实节点**（不是复制），所以按钮、下拉、日志、事件监听全部照旧可用；关闭后按原顺序放回原位，反复开关不坏。
- 宽屏（>700px）不建面板，也不碰页面。

## 鹈鹕屏：朗读音量条（1.1.1）

- 位置：显示屏正下方、麦克风按钮正上方，一条 38dp 深色半透明圆角细条（不挤压显示屏：页面底部预留了 240px）。
- 左端 🔊 图标＝一键静音（变 🔇，滑条归 0），再点恢复上次音量；右边 0–100 滑条，右侧显示百分比。
- 拖动实时生效、松手保存；拖到 0 自动静音，从 0 拖起来自动解除静音并记住新的非零值；冷启动/切屏回来都保持。
- **只控制鹈鹕页的朗读（WebAudio）**：注入脚本给 `AudioNode.prototype.connect` 打补丁，所有连到 `ctx.destination` 的连接改接每 context 一枚的 `masterGain`（`masterGain.gain.value = 音量/100`，用 `setTargetAtTime(…, 0.05)` 平滑）。全程**不调用 AudioManager、不改系统媒体音量**，助手屏完全不受影响。
- 只在鹈鹕屏显示；切到助手屏不会发出任何音量指令。

## 语音输入（鹈鹕屏底部）

圆形大按钮（72dp）+ 录音时才出现的「取消」。

1. 第一次点麦克风 → 申请 `RECORD_AUDIO` 权限。拒绝会提示；永久拒绝会给「去系统设置」的跳转。
2. 开始录音：按钮变红并脉冲、出现实时波形（30 根对称竖柱，青绿→蓝渐变，30fps）、状态显示「在听…点一下结束 Ns」。
3. 再点一下 → 停止 → 自动上传转写（**上限 60 秒自动停**）→ 转写成功后自动写进页面 `#text` 并点 `#send`，走与「文字兜底」完全同一条 `text.input`；状态显示「已发送：<文本>」，页面 `#transcript` 里也能看到。
4. 任何时刻点「取消」= 立刻停止录音、断开在途上传、清空待发文本，**一字节都不发**，并提示「已取消，没有发送」。
5. 失败可重试：转写为空 / HTTP 失败会给出中文原因，再点麦克风重录；若是「转写成功但页面没确认发送」，再点麦克风会用同一段文字重发。
6. 结果提示（已发送 / 没听清 / 已取消 / 权限 / 页面未就绪）都是**语音条正上方居中的小胶囊，2 秒自动淡出并 GONE**，新提示覆盖旧提示并重置计时；录音开始/结束、取消、切屏、退到后台会立刻收起。设置面板开着时不弹（避免盖住面板）。

录音规格（真录音，不是动画）：`AudioRecord` 16 kHz / 单声道 / 16 bit PCM → 44 字节标准 WAV 头 → `POST {origin}/tihu/asr`（`Content-Type: audio/wav`，读超时 45s）。

**ASR 地址不用填**：由「鹈鹕地址」的 origin 自动推导 = `origin + /tihu/asr`（例：`http://49.234.20.84:7080/tihu?token=…` → `http://49.234.20.84:7080/tihu/asr`）。若是 `http://` 明文且请求失败，错误提示里会直接说明。

### 转写靠什么

1. **插件自己的接口**（推荐）：`POST {origin}/tihu/asr` 由插件在鉴权后接走（`src/tihu/lane.ts` 的 `handleHttp`，`src/pocket-host/proxy.mjs` 的 tihu 分支），转写走 `transcribeDetailed`：**本地 whisper（`whisper/` 目录 + `127.0.0.1:3097`，默认 medium）优先 → 宿主 speech 回退**。
2. **公网隧道** `49.234.20.84:7080` 那条 relay 也实现了同一个 `/tihu/asr`，只用于反代；换成局域网 `http://<电脑IP>:3081` 时走的就是插件本体，不需要 relay。

> 页面里自带的「按住说话」在公网 `http://IP:7080` 下拿不到麦克风（浏览器只在 https/localhost 给 `getUserMedia`），所以手机上的语音入口用的是 APK 这套 AudioRecord + `/tihu/asr`。

## 语音唤醒（Porcupine）

唤醒词默认「鹈鹕」，用 Picovoice Porcupine 在手机本地识别，**音频不出手机**，也不需要逐帧上传电脑。

**取素材（一次性，免费）**
1. 打开 <https://picovoice.ai> 注册账号 → 控制台 Console → Porcupine。
2. 新建唤醒词：语言选中文（Mandarin），填「鹈鹕」，平台选 Android → 生成后下载 `.ppn` 文件。
3. 同一个页面上复制 **AccessKey**（一串几十位的字符）。

**手机上填两样**
1. 鹈鹕屏 → 音量条右端齿轮 → 「鹈鹕设置」→「语音唤醒（Porcupine）」卡片。
2. 把 AccessKey 粘进输入框 → 「保存 Key」；点「选择 .ppn」挑刚下载的文件（会复制到应用私有目录，之后重启不用再选）。
3. 两样齐了「语音唤醒」开关才会亮；没配齐时开关置灰并提示去哪里取材，其它功能照常用，不会弹错误框。

**它怎么工作**
- 只在**鹈鹕屏可见 + App 在前台**时监听；切屏、退到后台、锁屏立刻停止并释放引擎（省电，也避免和录音抢麦）。
- 命中「鹈鹕」：短振动 + 胶囊提示「在听…」→ 释放 Porcupine → 用 AudioRecord 录一句（**末尾静音 1.2 秒自动结束，最长 30 秒**）→ 走和麦克风按钮同一条 `/tihu/asr` → 填 `#text` → 点 `#send` → 约 0.3 秒后自动恢复监听。
- 取消/切屏会中断录音并恢复监听；录音期间 Porcupine 一定是停着的。

**自检区**
- 卡片下方列出最近 10 次事件（时间 / 关键词 / 灵敏度或错误），监听中状态行会写「正在听「鹈鹕」」。
- 初始化失败会把 Porcupine 的**原始错误类名 + 原文**贴出来（例如 `PorcupineKeyException：Invalid AccessKey`），下面再补一句中文建议；点「重新加载引擎」重试。
- 首次初始化需要联网做一次校验；之后可离线。

**常见问题**：误唤醒多 → 把灵敏度从 0.5 往下调（0.3~0.4）；唤不醒 → 调高到 0.6~0.7 并靠近说；换唤醒词 → 在控制台重新生成 .ppn 再选一次即可。

## 悬浮球可拖动 / 语音命令附带界面摘要（1.2.3）

- 左下角切屏球长按可拖动（跟着手指走、夹在屏幕内），松手记住位置，重启保持；设置面板里有「还原悬浮球」一键回左下角。短按仍是切屏，拖动不会误触发。
- 音量条、麦克风、波形、取消胶囊、切屏球这些原生浮层**只在鹈鹕屏可见**：助手屏、启动默认屏、设置面板打开时一律隐藏（设置面板是页面内 DOM，开关面板会通知原生收起浮层）。助手屏要切到鹈鹕屏走返回键菜单里的「切到鹈鹕屏」。
- 语音下命令时，APK 会先把**当前界面实际内容**（棋盘各行文字/状态、第 N/M 页、等你/在跑/排队/完成计数；非棋盘态抓标题、列表、完成页正文、澄清候选）拼成一条「原话 +【当前界面】摘要」再发，摘要 ≤400 字，全部来自 DOM；读不到界面就报错不发送。

## 重新构建

```powershell
powershell -ExecutionPolicy Bypass -File D:\dsh-assistant\android\build.ps1 -Flavor generic -VersionName 1.1.2 -VersionCode 7
# 可选：-Sdk D:\android-sdk  -Jdk "C:\Program Files\Eclipse Adoptium\jdk-17.0.17.10-hotspot"
```

- 依赖：`D:\android-sdk`（platform 34 + build-tools 34.0.0）、JDK 17。

## 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 助手屏白屏 / 连不上 | 电脑没开、DSH 没起、公网隧道断了；先用同一个 WiFi 的 `http://<电脑IP>:3081` 试。 |
| 鹈鹕屏打不开 | 检查隧道：`curl http://49.234.20.84:7080/tihu?token=96528673` 是否 200；断了重跑 `start-tunnel.cmd`。 |
| 点麦克风没反应 | 权限被拒：系统设置 → 应用 → 个人助手 → 权限 → 麦克风。 |
| 录音有声音但转写为空 | 本地 whisper（3097）没起，宿主也没装 speech；看 `~/.dsh/tihu/lane.log` 的 `tihu-asr` 行。 |
| 提示「已转写，但页面没确认发送」 | 页面没加载完 / `#send` 不存在；等页面就绪再点（会用同一段文字重发）。 |
| 转写很慢 | medium 模型在 CPU 上约 1.5–15s（看音频长度）；可用 `?model=small` 的 relay 变体或换 CUDA 版 whisper。 |
| 地址填错想改 | 长按返回键 1 秒 → 改地址；或长按桌面图标「设置地址」。 |
