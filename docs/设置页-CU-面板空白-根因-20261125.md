## 1. 结论

`src/client/assistant-settings.tsx` 第 142 行的块注释 `/**` 缺闭合，把 143 行注释文案之后直到第 380 行的
`/* ... */` 收尾之前的所有代码（含 `useModelCatalog`、`ComputerUsePanel` 两个函数定义）整段吞进注释；
语法仍合法（esbuild 不报错、构建成功），但产物里 `section === 'cu'` 分支引用的是自由变量
`ComputerUsePanel` → 运行时该分支抛 `ReferenceError`，被 React 边界吞掉 → Computer Use 分区空白。
补一行 ` */` 后重建，产物恢复正常。

## 6. 同类损伤扫描（`src/client` 下 `.ts` / `.tsx`）

脚本 `.tmp/scan-comment-damage.mjs`，判据与本次 bug 完全一致：

1. 字符级状态机走全文（跳过 `//`、`'`、`"`、`` ` `` 内容），每遇到 `/*` 或 `/**` 记录起始行，找下一个 `*/`；
2. 若未找到 `*/` → 直接报「文件末尾仍未闭合的块注释」；
3. 对块注释**内部**（不含首行和收尾行）的每一行，去掉首尾空白后：若以 `*` / `//` / `/*` / `*/` 开头则跳过（正常注释格式），
   否则若匹配 `^(export\s+)?(default\s+)?(async\s+)?(function|class|interface|type|enum|const|let|var)\s+<名字>` 或 `@<名字>`
