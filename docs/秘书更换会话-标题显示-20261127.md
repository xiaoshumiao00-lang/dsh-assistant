# 控制室「更换会话」：以会话标题为主显示（2026-11-27）

## 用户实测现象

控制室 → 「个人秘书」卡片 → 「更换会话」→ 弹层「给个人秘书换一条会话」里每一条只显示
`session-83bca3e3-bcd1-49f0-8b3c-2ec9edae14e3` 这种原始会话 id；搜索框提示「搜索会话标题 / 目录…」，
但条目上没有标题，按标题也搜不到。

## 根因（不是渲染层写错，是数据源里就没有标题）

宿主 `sessionQuery.listSessions()` 回来的记录形状是 `{ header, live, persisted, formatStatus }`，
而 `header` **只有身份字段**：

```
{"type":"session","version":4,"id":"session-83bca3e3-…","createdAt":1795263410880,
 "cwd":"C:\\Users\\<ACCOUNT>\\.dsh\\assistant","isSeeded":false,"delegationDepth":0,
 "agentPreset":"standard"}
```

没有 `title` / `displayTitle`，所以 `normalizeBindableSessionRow()` 只能落到 `|| id` 兜底 → 面板显示原始 id。

现场证据（本机宿主 127.0.0.1:50864 实测）：

```
GET /api/assistant/secretary/sessions?limit=6
items[0].title = "session-83bca3e3-bcd1-49f0-8b3c-2ec9edae14e3"   ← 就是 id
items[0].cwd   = "C:\\Users\\<ACCOUNT>\\.dsh\\assistant"
```

标题的真实位置在**会话日志 fold 出来的投影行 `title`** 里。宿主自己的会话列表也是这么取的：

- `@deepseek-ai/dsh-session-title`：`titleProjectionDefinition = { key: 'title', … }`（日志事件 `session/title`）；
- `@deepseek-ai/dsh-session-projection-cache`：`storages/session_projcache/sessions/session-<id>.json`
  的 `record.rows.title.val`（实测 `session-83bca3e3` → `"个人秘书"`，`session-5c295820` → `"修复秘书历史消息加载后跳转最新问题"`）；
- `@deepseek-ai/dsh-api-session-controller#projectionsFor()`：
  活会话走 `ctx.sessionProjections.cachedSnapshot(session)`，冷会话走 `ctx.get('sessionProjectionCache').cachedSnapshot(header)`
  / `cachedPredecessorTitle(header)` —— 侧栏标题就是从这两处来的。

身份判据也核对过：`lifecycleIdentityOf(header) = { formatVersion: header.version, createdAt, cwd, isSeeded }`，
与 header 字段一一对得上（`version:4 / createdAt / cwd / isSeeded:false`），所以 `cachedSnapshot(header)` 能命中真实缓存记录。

## 改法

1. **宿主半部（权威）** `src/assistant-secretary.ts`
   - 新增 `titleFromProjectionBlock(block)`：从 `{ asOfSeq, values: { title } }` 取标题，形状不对回空串；
   - 新增 `resolveHostSessionTitle(ctx, header, live)`：活会话 → `ctx.sessionProjections.cachedSnapshot(session)`；
     冷会话 → `ctx.get('sessionProjectionCache').cachedSnapshot(header)`，跨世代再退 `cachedPredecessorTitle(header)`；
     最后兜底 `ctx.sessionTitle.get(session)`；全取不到就回空串（保留 id 兜底，**不许因为没标题把会话丢掉**）；
   - `collectHostSessionRows()` 改成先收 `{ header, live }` 再归一，标题仍是 id 的行去投影缓存补标题。
2. **页面半部（老宿主不重启也能看）** `src/client/secretary-session-switch.ts` + `src/client/index.tsx`
   - `snapshotSessionTitle(byId, id)` / `fillSwitchRowTitles(rows, byId)`：从本页会话列表快照的投影行
     （`projectionValues.title` / `projections.values.title` / `displayTitle` / `title`，兼容 `{val}`/`{value}` 包装）
     补「标题还是 id」的行；
   - `getSecretarySessions()` 拿到宿主答复后先补一遍标题，再交给面板。
3. **面板显示口径** `src/client/split.tsx` + `styles.ts` + `locales.ts`
   - `switchRowName(row)`：主行永远显示标题；标题就是 id 时显示「未命名会话」（id 不许顶到主行）；
   - `shortSessionId(id)`：次要行显示 `83bca3e3`（`session-` 之后前 8 位）；
   - 行结构 = 主行标题（加粗提亮）+ 次要行（当前绑定标签 / 时间 / id 短名），tooltip = 标题 · 完整 id · 目录；
   - 搜索判据不变（标题 / id / 目录都能搜），标题补上后按标题搜索自然可用。

## 生效方式与残留风险

- 页面半部（补标题 + 新显示口径）：**手机/桌面刷新页面即生效**，不用重装 APK；
- 宿主半部（全量语料按标题搜索，含 200 条窗口外的会话）：**要重启宿主**才加载新 bundle，本次没有重启；
- 若某条会话的投影缓存被清过（`storages/session_projcache` 缺这条），该行显示「未命名会话」+ id 短名，
  点进去什么都不影响（只是名字不可读）。
