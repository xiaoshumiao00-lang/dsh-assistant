# 平板 / 电视上怎么验（2026-11-06）

改动都在插件侧（页面），**不用重装 APK**：把页面下拉刷新，或杀掉 APK 重开即可。

## 一、控制室卡片

1. 点悬浮球打开控制室；
2. 看两点：
   - 卡片是否**按屏幕宽度排成 5～6 列**（960×540 的平板/电视：5 列，卡片约 174 px）；
   - **第二行是否完整可见**（之前会被屏幕下边缘裁掉，末尾那张「添加项目」看不到）。
3. 底部工具条最后一颗按钮可以手动改列数（自动 / 1-5 列），手动值优先。

## 二、抽屉里点会话

1. 点左上角 ☰ 打开抽屉；
2. 会话列表应当能点到至少 2～3 行（之前整屏只有 1 行是真正可点的，其余被裁掉或压在
   底部「陈潘 / 账号」那一行下面，点下去没反应）；
3. 点一行 → 抽屉收起、右侧出现会话正文。

> 只在 <660 px 高的视口生效；手机竖屏（≥700 px 高）不受影响，行为和以前一样。

## 三、如果「载出会话」还是慢

这不是插件能改的（实测：插件空闲流量只有 0.5 KB/s）。慢在两个地方：

1. **每次打开都要重传 594 KB 会话列表**（2627 条）。同一 WiFi 下开会话归档能直接缩短它；
2. **公网隧道本身**。平板如果和电脑在同一个 WiFi，可以走局域网：
   - 电脑上：DSH → 设置 → 个人助手 → 手机访问 → 打开「局域网访问」；
   - APK：长按返回键（或长按桌面图标）→ 设置地址 → 填 `http://192.168.126.222:3081`。
   - 局域网直连没有隧道那一段，列表加载会快一个数量级；代价是出门在外要改回公网地址。

## 四、复现 / 取证脚本（本机）

在电脑上跑（需要 `~/.dsh/dsh-pocket/token` 或 `token-lan` 里的访问密码）：

- 控制室量尺寸：`node console.mjs 960 540` → 输出列数、卡宽、卡片盒模型并截图；
- 触摸点会话：`node touch.mjs 960 540` → 打开抽屉、真触摸点一行、报 current 变化；
- 首屏/重复打开流量：`node net2.mjs 960 540`；
- 空闲流量：`IDLE_MS=45000 node idle.mjs 960 540`。

脚本与截图在 `C:\Users\Administrator\.dsh\assistant\outputs\2026-11-06\`。
