# 个人助手（dsh-assistant）安装说明 · 给别人的一页纸

> 目标：在**你自己的电脑**上装好这个插件，然后用手机（或平板）连上你自己的电脑。
> 全程不需要作者的机器、VPS 或任何账号。

---

## 0. 前提

| 项 | 要求 | 说明 |
| --- | --- | --- |
| 电脑 | Windows 10/11（macOS / Linux 也可，功能略降级） | 页面本身跑在电脑上，电脑要开着 |
| DSH | DeepSeek Harness 桌面版，**≥ 0.1.5** | 插件是 DSH 的扩展，不能单独运行 |
| Node.js | ≥ 22 | DSH 桌面版自带运行时；用命令行装就要自己装 |
| 网络 | 能访问 GitHub | 安装要拉一次仓库 |

---

## 1. 装插件（选一种）

### 方式 A · 在 DSH 里点两下（推荐，桌面版）

1. 打开 DSH → 左侧 **「插件」** 页
2. 点 **「添加插件 / Add plugin」**
3. 在输入框里粘贴这一整行，回车：

   ```
   github:xiaoshumiao00-lang/dsh-assistant
   ```

4. 等它拉包、装依赖（第一次要几十秒到几分钟）→ **完全退出并重启 DSH Desktop**

### 方式 B · 命令行（`dsh web` 或服务器上的 profile）

```bash
dsh plugin --profile web add github:xiaoshumiao00-lang/dsh-assistant
```

> 桌面版不要用命令行：`--profile desktop` 由 Electron 独占，命令行会直接报
> `profile "desktop" is managed exclusively by the Electron application`。桌面版走方式 A。

### ⚠️ 千万别装错

**不要**在「添加插件」里只填 `dsh-assistant`。npm 上同名的 `dsh-assistant` 是**另一个项目**
（别人的 macOS 桌面宠物，作者 vianvio），装上去跟这里说的个人助手完全没有关系。
认准 `github:xiaoshumiao00-lang/dsh-assistant` 这个 Git 地址。

### 装好了怎么确认

重启后：

- 左侧导航多出 **「个人助手」**；
- 悬浮球出现在屏幕右下角；
- 设置里多出 **设置 → 个人助手**（含「手机访问」「本机配置」等 tab）。

---

## 2. 开一个「手机访问」入口

设置 → **个人助手** → **📱 手机访问**：

| 场景 | 怎么做 | 拿到的地址 |
| --- | --- | --- |
| 同一个 WiFi（最简单） | 打开 **局域网访问** 开关 | `http://192.168.x.x:3081` |
| 要在外面用 | 配隧道：Cloudflare 命名隧道（要有域名）或 SSH 反向隧道（要有 VPS） | 固定的公网地址 |

同时记下这一栏里的 **8 位访问密码**——手机第一次连要输它。

> 同一时间只建议开一种入口。开公网入口前想清楚：这台电脑上能执行任意命令，
> 密码和扫码链接等于控制权，别外发。

---

## 3. 手机装 APK 并填地址

1. 把 `个人助手-<版本>.apk` 传到手机安装（允许一次「未知来源」）。
2. 打开「个人助手」，第一次会进设置页：填第 2 步拿到的地址 → 点「连接」。
3. 输入一次访问密码；之后 30 天免输，地址也记住了，以后打开直接进。
4. 想换地址：**长按桌面图标 → 设置地址**（没有返回键的手机也能进）。

不想装 APK 也行：手机浏览器（或微信里）直接打开那个地址，界面一模一样，只是多一层浏览器壳。

---

## 4. 装完建议填的几项（设置 → 个人助手 → 本机配置）

| 分组 | 填什么 | 不填会怎样 |
| --- | --- | --- |
| 目录与路径 | 默认项目父目录、技能根目录（通常 `~/.dsh/skills`） | 新建项目落到系统桌面 |
| 语音词表 | 自己的人名 / 校名 / 店名（听到 → 改成） | 专有名词转写不准 |
| 目录边界 | 一般不用填；要访问别的盘再加 | 内容窗访问那些盘会 403 |
| 更新检查 | 默认关闭；填自己的 `owner/repo` 才会联网 | 保持关闭 = 完全不联网 |

## 5. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 装完没有「个人助手」入口 | 没重启 DSH；或装的是 npm 上那个同名项目 |
| 手机连不上 | 电脑没开 / 不同 WiFi / 隧道没起来；先在本机浏览器打开那个地址试试 |
| 手机上一行 `dsh web authentication required` | DSH 重启后端口变了、旧 cookie 失效：用 1.0.2+ 的 APK（会自动修复），或在浏览器访问 `地址/?dsh-pocket-auth=1` |
| 语音输入没反应 | 语音要 https（或 localhost）入口，纯 `http://IP` 拿不到麦克风 |
| 装依赖失败（koffi） | 不影响启动，只是「点球把 DSH 提到前台」这一项不可用，设置页会标出来 |
| 想升级 | 再来一次方式 A（重新粘贴同一行），或在命令行用 `dsh plugin --profile web update dsh-assistant` |
| 想卸载 | 插件页停用/移除该插件，然后重启 DSH |

## 6. 安全与许可

- 许可是 **GPL-2.0**：转发请连同源码与 `LICENSE` / `NOTICE` 一起。
- 插件让手机能操作这台电脑（读写文件、跑命令）。只在信任的手机与网络上开公网入口，
  密码被猜中的风险由公网入口自己承担；用完可以在设置里关掉该入口。
