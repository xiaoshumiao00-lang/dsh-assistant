# 风格说明（取自真实界面，非凭空造 UI）

## 取证方式
- 手机侧：headless Chrome（CDP，390×844 + deviceScaleFactor 2）打开 pocket 代理 `http://127.0.0.1:3081/?token=<LAN token>`，先注入 `dsh.assistant.firstRunGuide.v1 = {done:true,seenAll:true}` 关掉首跑引导，再点进工作区「09-英文翻译」的会话，得到真实聊天页 → `ref-pocket-chat.png`、`ref-pocket-list.png`、`ref-pocket.png`。
  （直连 `http://127.0.0.1:65277` 无 launch token 会 401，代理会注入 token，所以用 3081。）
- 电脑侧：同一页面加 `&dsh-layout=desktop`（`layout-mode.mjs` 的 `LAYOUT_URL_PARAM='dsh-layout'`），1440×900 截图 → `ref-web.png`、`ref-web-chat.png`（真实侧边栏 280px + 会话窗口）。
- 样式值来源：live-rules.txt（CDP 导出 141 条真实规则）+ computed style 探针（act-bg.js/act-colors.js）+ PIL 取色（probe.py）。
